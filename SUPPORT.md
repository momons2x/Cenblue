# Support

Use [GitHub Issues](https://github.com/momons2x/Cenblue/issues) for reproducible bugs and feature requests after checking the README troubleshooting section.

Include the Cenblue commit, Windows version, Node/pnpm versions, browser channel, affected command, expected behavior, actual behavior, and sanitized errors. Do not upload private runtime data or media.

Security issues belong in private vulnerability reporting, not public support channels.
